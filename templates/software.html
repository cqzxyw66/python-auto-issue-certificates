如何生成客户端程序

服务端通常部署在 Linux/Docker 上，无法生成 Windows 的 exe， 因此客户端程序由管理员在自己的 Windows 电脑上打包后上传到本服务器。

第 1 步：获取「客户端打包工具」

{% if builder_exists %}

管理员专用的 Windows 打包工具，已在服务器上就绪（{{ builder_size }}）。

📥 下载客户端打包工具 {% else %}

服务器上还没有打包工具文件（{{ builder_name }}）。请把开发者提供的该文件放到服务器 config 目录，刷新本页后即可在此下载。

{% endif %}

第 2 步：在 Windows 上打包并上传

  1. 在一台 Windows 电脑上运行打包工具（首次运行会自动检查并安装 Python 环境）。
  2. 在工具中填写本项目的访问地址：{{ configuration.url }}。
  3. 点击“开始生成客户端”，工具会自动下载源码、配置环境并打包出 {{ executable_name }}。
  4. 打包完成后工具会自动上传到本服务器；刷新本页面即可下载、分发给同事。

若自动上传失败，可把生成的 exe 手动放到服务器 config 目录，文件名保持为 {{ executable_name }}。
